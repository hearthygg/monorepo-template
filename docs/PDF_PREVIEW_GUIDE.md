# PDF预览功能使用指南

## 功能概述

PDF预览功能基于PDF.js实现，提供了完整的PDF文档预览体验，支持多种交互操作。

## 主要功能

### 1. 基础预览
- 自动加载PDF文档
- 显示文档信息（页数、标题、作者等）
- 自适应页面大小

### 2. 页面导航
- **上一页/下一页按钮**：点击切换页面
- **页面指示器**：显示当前页码和总页数
- **键盘快捷键**：
  - `←` 上一页
  - `→` 下一页

### 3. 缩放控制
- **放大/缩小按钮**：点击调整缩放比例
- **缩放比例显示**：实时显示当前缩放百分比
- **鼠标滚轮**：使用滚轮进行缩放
- **适应页面**：一键调整到最佳显示大小
- **键盘快捷键**：
  - `+` 或 `=` 放大
  - `-` 缩小
  - `0` 适应页面

### 4. 全屏预览
- **全屏按钮**：切换全屏模式
- **键盘快捷键**：`F` 切换全屏

### 5. 文件操作
- **下载按钮**：直接下载PDF文件
- **文件信息显示**：文件名、大小、创建时间

## 技术特性

### 性能优化
- 使用Canvas渲染，性能优异
- 按需加载页面内容
- 内存管理优化

### 兼容性
- 支持所有现代浏览器
- 基于PDF.js，兼容性良好
- 响应式设计，适配不同屏幕

### 错误处理
- 加载失败时显示错误提示
- 提供重试功能
- 友好的错误信息

## 使用示例

```vue
<template>
  <PDFPreview
    :file="pdfFile"
    class="h-full"
  />
</template>

<script setup>
import PDFPreview from '@/components/WindowManager/PDFPreview.vue'

const pdfFile = {
  name: 'document.pdf',
  path: '/api/files/document.pdf',
  size: 1024000,
  createdAt: '2024-01-01T00:00:00Z',
  ext: 'pdf'
}
</script>
```

## 配置选项

PDF预览组件支持以下配置：

- `file`: 文件对象，包含文件信息
- `class`: 自定义CSS类名
- 自动处理文件路径和加载

## 注意事项

1. **文件路径**：确保PDF文件路径可访问
2. **跨域问题**：如果PDF文件在不同域名，需要配置CORS
3. **大文件**：大文件可能需要较长加载时间
4. **浏览器支持**：建议使用现代浏览器以获得最佳体验

## 故障排除

### 常见问题

1. **PDF无法加载**
   - 检查文件路径是否正确
   - 确认文件格式为PDF
   - 检查网络连接

2. **显示异常**
   - 刷新页面重试
   - 检查浏览器兼容性
   - 清除浏览器缓存

3. **性能问题**
   - 检查PDF文件大小
   - 关闭其他占用内存的应用
   - 使用更快的网络连接
